
# Global Superstore Sales & Profitability Analysis Dashboard

## Project Overview

This project analyzes sales and profitability using the Global Superstore dataset containing 51,290 transactions.

The dashboard was created using WPS Spreadsheet/Excel to identify sales trends, profitable categories, loss-making products, discount-related issues, and regional performance.

## Tools Used

- WPS Spreadsheet/Excel
- PivotTables
- PivotCharts
- Data Cleaning
- KPI Analysis
- Dashboarding
- Business Analysis

## Key KPIs

- Total Sales: $12,642,501.91
- Total Profit: $1,467,457.29
- Total Transactions: 51,290
- Average Transaction Value: $246.49
- Loss-Making Transactions: 12,544
- Overall Profit Margin: 11.61%

## Key Findings

- Technology generated the highest sales and profit.
- Furniture had the lowest profit margin among the three categories.
- Tables were a weak-performing Furniture sub-category.
- Higher discount levels were associated with lower total profit.
- Western Europe was the strongest region by sales and profit.
- Some regions and products recorded negative profitability.

## Business Recommendations

- Review high-discount transactions.
- Investigate the negative profitability of Tables.
- Review pricing, shipping costs, and discount policies.
- Study low-profit regions.
- Focus on profitable products while improving weak-performing areas.
